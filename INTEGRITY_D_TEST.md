# Integrity Part D: browser checklist (Roman Urdu)

App: http://localhost:7310 (pehle `npm run build` phir `npm run start`). Candidate: `candidate@demo.test`. Recruiter: `recruiter@demo.test`, doosri company ka recruiter: `recruiter.zainab@demo.test`. Admin: `demo.admin@demo.test`.
Tayyari: candidate se koi test shuru karein aur test chalte hue doosre tab par jaa kar **1 ya 2 baar** wapas aayein (threshold ke neeche), phir ek aur test mein **3 baar** (threshold = 3, Settings > Tests mein dekh sakte hain). Dono test poore kar lein.

- [ ] 1. Recruiter login > **Candidate search**: table mein nayi column **Integrity**. Jis candidate ke koi exit nahi: "✓ No concerns". 1-2 exits wale: sirf "2 exits" **grey** mein (sirf maloomat). 3 ya zyada: "⚠ 3 exits" **surkh** (red) mein. Sirf ginti dikhe, aur kuch nahi.
- [ ] 2. Mouse ko ⚠ wali ginti par le jayein: tooltip mein har test ke hisaab se exits likhe hon (jaise "IQ: 3 exits").
- [ ] 3. Filter **"Only candidates with no integrity concerns"** tick karein > Search. Address bar mein `clean=1` aaye. Sirf woh candidate list se hat'te hain jinke exits threshold ya us se zyada hain; "✓ No concerns" aur grey wale rahte hain. Page refresh/bookmark karne par filter wahin rahe.
- [ ] 4. Admin: Audit log ya Integrity review se us candidate ka test **Clear flag** karein. Recruiter search dobara: us candidate ki integrity ab "✓ No concerns" (cleared flag = koi concern nahi). Void result karne par bhi yehi hota hai.
- [ ] 5. Recruiter: candidate ka naam kholein (report). Har test ke neeche wohi teen halatein: "✓ Integrity: no concerns", grey "Integrity: 2 window exits", surkh "⚠ Integrity: concern, 3 window exits". "Download PDF report" mein bhi har test ke neeche yehi lines hon, aur sab se upar ek line "Integrity (most window exits in one test): ...".
- [ ] 6. Report page par kisi test ke neeche **Report a concern** dabayein. Reason khali ho to "Send report" band rahe. Chhota sa reason likhein (max 500 huroof, counter dikhe) > Send. Likha aaye "Your company reported a concern about this result on ...". Page refresh: button wapas nahi aata (ek company ek test sirf ek baar report kar sakti hai).
- [ ] 7. Admin login: sidebar mein notification ka number badhe ("A company reported an integrity concern"). **Integrity review** kholein: naya hissa **"Reported by companies"**: company, recruiter, candidate, test, reason, tareekh. **Mark reviewed** dabayein: report "Reviewed reports" mein chali jaye. Audit log mein "CONCERN REPORTED" aur "CONCERN REVIEWED" entries hon. Admin ke pas hi Clear/Void ka haq hai (recruiter ke pas nahi).
- [ ] 8. Doosri company ka recruiter (`recruiter.zainab@demo.test`) us candidate ki wohi report kholein: use apni taraf se **dobara report** karne ka option mile (pehli company ki report usay nazar nahi aati). Pehli company ko apni report ka "reported" message hi dikhe; doosri company ki koi report nazar na aaye.
