# Integrity Lite: browser checklist (Roman Urdu)

Login: `candidate@demo.test` (candidate) aur platform admin. App: http://localhost:7310 (pehle `npm run dev` ya `npm run start`).
Note: `candidate@demo.test` ke Language aur Job skill tests abhi baqi hain, in mein se kisi ek se test karein.

- [ ] 1. Candidate login karein, My tests > koi test (e.g. Language) kholein. "I will take this test myself, without help from other people, websites or AI tools." wala checkbox nazar aaye aur "Start the test" button grey (disabled) ho.
- [ ] 2. Checkbox tick karein: button chal jaye. Untick karein: button dobara disabled ho. Phir tick karke Start karein.
- [ ] 3. Test screen par sawal ka text mouse se select karne ki koshish karein: select nahi hona chahiye (options par bhi).
- [ ] 4. Sawal ya options par right-click karein: koi menu nahi khulna chahiye. Ctrl+C sawal par: kuch copy nahi hoga.
- [ ] 5. Doosra tab kholein (ya Alt+Tab), thori dair baad wapas test tab par aayein: surkh (red) notice "You left the test window. This has been recorded." nazar aaye. "Dismiss" se band ho.
- [ ] 6. Notice ke baad timer chalta rahe aur test jari rahe (pause ya khatam nahi hona chahiye); agla sawal normal answer ho.
- [ ] 7. Language test mein MCQs ke baad writing box par jayein. Kahin se text copy karke Ctrl+V karein: box mein kuch paste na ho, aur "Pasting is not allowed in this test" likha aaye. Khud type karna normal chale.
- [ ] 8. Platform admin login karein > Audit log. "What happened" filter mein "Candidate left the test window" chunein: step 5 ki entries dikhen (Details mein testType aur count, jaise count 1, 2...). Koi jawab ya zaati maloomat nahi honi chahiye.
- [ ] 9. Admin > Settings > Tests: "Honesty pledge" ka text badal kar save karein; candidate ki test start screen par naya text nazar aaye. Phir purana text wapas kar dein.
- [ ] 10. Mobile size (browser ko chhota karein ya phone) par bhi pledge, notice aur paste-block theek kaam karein, aur screen side ko scroll na ho.
